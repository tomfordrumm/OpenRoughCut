OpenRoughCut 0.1.3 improves local speech editing, transcription quality controls, project handling, and portrait-video workflows.

## What changed

- Automatically removes isolated sighs, clicks, humming, and other sounds without recognized words while protecting nearby speech.
- Uses exact Whisper token timing and keeps uncertain non-verbal detections available for review.
- Improves false-start and repeated-take detection across quick retries and multi-take chains.
- Adds Base, Small, and Large-v3 Turbo transcription model choices with pinned, verified downloads.
- Adds native portrait-media detection and vertical UHD 4K and Full HD timeline presets.
- Adds an explicit Close project flow that clears recovery state safely.
- Refreshes stale proxy metadata without rebuilding valid playback media.
- Keeps the static download site usable in Chrome by removing the unused client router and smooth-scroll trap.

## Downloads

- macOS Apple Silicon: DMG or ZIP (`mac-arm64`)
- macOS Intel: DMG or ZIP (`mac-x64`)
- Windows 64-bit: NSIS installer (`win-x64.exe`)
- `SHA256SUMS.txt`: SHA-256 verification hashes for every binary

> [!WARNING]
> These binaries are unsigned because this project does not currently have Apple Developer ID or Windows Authenticode certificates. macOS Gatekeeper and Windows SmartScreen may display security warnings. Verify downloads against `SHA256SUMS.txt` before running them.
