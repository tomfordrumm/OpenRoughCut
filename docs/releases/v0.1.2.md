OpenRoughCut 0.1.2 improves project switching and playback, and makes Windows file-opening failures diagnosable.

## What changed

- Shows video inspection progress and file-opening errors on the welcome screen.
- Adds a rotating diagnostic log with one-click access from the toolbar, setup screen, and file error.
- Records runtime checks, FFprobe results, operation failures, and renderer crashes.
- Stops media inspection after one minute with guidance for cloud or network files.
- Adds safe new/open project switching with save-before-switch controls and keyboard shortcuts.
- Improves proxy seeking across removed regions with bounded keyframe spacing.

## Downloads

- macOS Apple Silicon: DMG or ZIP (`mac-arm64`)
- macOS Intel: DMG or ZIP (`mac-x64`)
- Windows 64-bit: NSIS installer (`win-x64.exe`)
- `SHA256SUMS.txt`: SHA-256 verification hashes for every binary

> [!WARNING]
> These binaries are unsigned because this project does not currently have Apple Developer ID or Windows Authenticode certificates. macOS Gatekeeper and Windows SmartScreen may display security warnings. Verify downloads against `SHA256SUMS.txt` before running them.

## Validation

- Automated application and website tests
