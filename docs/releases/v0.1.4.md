# OpenRoughCut 0.1.4

## Editing

- Detect more false starts and repeated takes while protecting speech you keep.
  Partial cuts use measured word timings. When an exact cut cannot be made, the
  suggestion stays in the transcript for review.
- Trim empty pauses next to deleted speech. Respect manual keep and remove
  decisions in both preview and export.
- Show the target timeline dimensions before exporting and report missing
  source media when opening or recovering a project.

## Under the hood

- The desktop app and CLI now share the same analysis and export pipeline.
- Updated Electron and build dependencies, tightened desktop IPC checks, and
  added notices for bundled libraries.

## macOS downloads

Choose the arm64 build for Apple Silicon or the x64 build for Intel. First-run
setup downloads the editing tools and your choice of local Whisper model.
